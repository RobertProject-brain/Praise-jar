# 실습구슬 모으기

언어재활 실습 시간을 기록하면 채운 시간만큼 구슬이 유리병에 담기는 휴대폰 웹 앱입니다.

## 설치 (아이폰)
1. Safari로 https://robertproject-brain.github.io/Praise-jar/ 열기
2. 아래쪽 공유 버튼 → 홈 화면에 추가
3. 홈 화면의 실습구슬 모으기 아이콘으로 실행 (Safari 창과 홈 화면 앱은 저장 공간이 따로라서, 기록은 아이콘으로 열어서 시작하세요)

## 저장
- 모든 기록은 그 휴대폰 안(브라우저 저장소)에만 저장됩니다. 설정 → 백업 저장으로 백업할 수 있습니다.

## 지도
- 지도: Leaflet, © OpenStreetMap contributors, © CARTO
- 장소 검색: Nominatim (OpenStreetMap), 도로 거리·경로: OSRM 공개 서버
- 장소 검색과 경로 계산 때 해당 좌표가 위 서버로 전송됩니다. 도로 거리는 자동차 도로 기준 근사값입니다.

## 실습 시간 기준
장애인복지법 시행규칙 [별표 6의2] 언어재활 관련 교과목: 언어재활관찰 30시간 이상, 언어진단실습·언어재활실습 합계 90시간 이상(교내 45시간 이상 포함).
